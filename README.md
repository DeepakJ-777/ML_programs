# ML_programs

Machine Learning lab programs written in Python.

## Structure

Programs live inside the `ML programs/` folder as `exp1.py`, `exp2.py`, and so on.

## Setup

Requires Python 3.12+.

```bash
python -m pip install numpy pandas matplotlib scikit-learn scipy seaborn
```

## Running a program

```bash
python "ML programs/exp1.py"
```
